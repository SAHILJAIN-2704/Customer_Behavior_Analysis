# 📊 Customer Behavior Analysis

An end-to-end **Data Analytics project** analyzing customer shopping behavior and retail trends using **Python, SQL, and Power BI**.

The project follows a complete analytics workflow: **business problem → data exploration → data cleaning → SQL analysis → Power BI dashboard → business insights → reporting and presentation**.

## 🔑 Project Highlights

- Analyzed **3,900 customer records** across **18 attributes**
- Performed EDA and data cleaning using **Python and Pandas**
- Analyzed customer behavior using **10 business-focused SQL queries**
- Used **CTEs, CASE statements, aggregate functions, and window functions**
- Built an interactive **Power BI dashboard**
- Prepared a detailed business report and presentation

---

## 🎯 Business Problem

Retail businesses need to understand how customers purchase products, respond to discounts, interact with subscriptions, and differ across customer segments.

This project analyzes customer shopping data to identify patterns that can support better understanding of **customer spending, product performance, purchasing frequency, discounts, and subscription behavior**.

### Key Business Questions

- What is the revenue generated by different customer groups?
- Do customers who use discounts still make higher-value purchases?
- Which products receive the highest ratings?
- How does shipping type relate to average purchase amount?
- Do subscribed customers spend more than non-subscribers?
- Which products have the highest discount usage?
- How can customers be segmented based on previous purchases?
- What are the most purchased products within each category?
- Are repeat buyers more likely to subscribe?
- Which age groups contribute the most revenue?

# 🔄 Project Workflow

### 1. Python — Data Loading & EDA

The dataset was loaded using Pandas and examined to understand its structure and data quality.

Activities included:

- Dataset structure and data type inspection
- Descriptive statistics
- Missing-value analysis
- Duplicate-value checks
- Categorical and numerical analysis
- Distribution analysis
- Exploratory visualizations

The dataset contains **3,900 records**, with **37 missing values in Review Rating** identified during the initial inspection.

**Notebook:** [Customer_Shopping_Behavior_Analysis.ipynb](./Customer_Shopping_Behavior_Analysis.ipynb)

---

### 2. Data Cleaning & Transformation

The data was prepared for analysis by:

- Handling missing values
- Checking duplicate records
- Correcting data types
- Standardizing values
- Creating derived fields where required
- Preparing the cleaned data for SQL and Power BI

---

### 3. SQL — Business Analysis

The cleaned data was analyzed using **PostgreSQL**.

The SQL analysis contains **10 business questions** covering customer revenue, product ratings, shipping, subscriptions, discounts, customer segmentation, product rankings, repeat buyers, and age-group revenue.

### SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate functions
- CASE WHEN
- Subqueries
- CTEs
- Window functions
- ROW_NUMBER()

**SQL file:** [customer_behavior_sql_queries.sql](./customer_behavior_sql_queries.sql)
